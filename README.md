> **Lightweight viewport capture and screenshot framing utility for instant, clean visual presentation of web applications.**

---

## Overview

**EmaF205 SNAP** is a focused browser tool designed for developers and product designers who need crisp, standardized viewport captures without bloated desktop recording software. It frames screenshots with precise aspect ratios, subtle translucent device frames, and instantaneous image export.

---

## Core Capabilities

- **Precision Aspect Ratios**: Native 16:9, 4:3, 3:2, and mobile 9:16 presets.
- **Clean Viewport Framing**: Translucent glass border overlay with zero decorative distortion.
- **Zero Cloud Uploads**: Image rendering and canvas compositing occur 100% locally in the browser memory.
- **High-DPI Canvas Export**: Produces razor-sharp PNGs and JPEGs suitable for documentation and social previews.
- **Extension or Standalone**: Can be loaded as an unpacked browser extension or run as a standalone web utility.

---

## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/emaf205/emaf205-snap.git
   ```
2. Open `capture.html` directly in your browser, or load `manifest.json` as an unpacked extension in Chrome/Edge.
3. Capture or paste your screenshot, adjust the frame guides, and export your framed image.
